# Security Policy

Nook runs with Accessibility (for the volume/brightness HUD) and other privacy permissions,
so security reports are taken seriously.

**Please don't open a public issue for security problems.** Report them privately through
[GitHub Security Advisories](https://github.com/siliconile/Nook/security/advisories/new).
Include steps to reproduce and the Nook / macOS versions. You'll get a reply as soon as
possible, and credit in the release notes if you'd like.

Only the latest release receives security fixes.
