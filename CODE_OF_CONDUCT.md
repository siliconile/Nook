# Code of Conduct

Nook follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, patient and respectful. Critique ideas and code, never people.
Harassment, discrimination, personal attacks and publishing others' private information
are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the maintainers using
GitHub's **Report content** option on the comment, or by opening a
[private security advisory](https://github.com/siliconile/Nook/security/advisories/new) marked
"conduct". Reports are handled confidentially, and maintainers may remove content or block
participants who break these rules.
